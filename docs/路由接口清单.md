# 路由接口清单

> 本清单依据软件需求规格说明书 6.2 整理；具体路径、方法与视图以最终代码 `urls.py` 为准。

## 1. 路由组与访问控制

| 路由组 | 职责 | 访问控制 |
| --- | --- | --- |
| `/accounts/` | 注册、登录、退出、找回邮箱、密码重置、资料与审核 | 按页面区分匿名、本人和管理员 |
| `/items/` | 商品创建、列表、详情、状态操作、下架、评价 | 登录、审核状态、角色和对象归属 |
| `/locations/` | 分类、成色标准、交易方式 | 普通用户读取启用项，管理员维护 |
| `/chat/` | P1 商品文字消息 | 买家或当前卖家，终止后只读 |
| `/admin/` | Django 管理入口或维护工具 | 仅授权维护人员 |

## 2. 通用规则

- 所有写接口限制 HTTP 方法，并进行 CSRF 校验。
- 非法方法、非法角色、对象越权和非法状态转移返回明确错误，不得静默成功。
- 服务端校验不得被客户端校验替代。

## 3. HTTP 状态码使用

| HTTP 状态 | 使用场景 | 页面或接口行为 |
| --- | --- | --- |
| 200 | 查询成功或表单校验失败后重新展示页面 | 展示数据；校验失败时在字段附近显示错误 |
| 302 | 登录、注册或写操作成功后的页面跳转 | 提交后重定向，避免刷新重复提交 |
| 400 | 请求字段缺失、格式错误或文件不合法 | 拒绝写入并返回可理解的错误信息 |
| 403 | 未登录业务访问、角色越权、对象越权或审核状态不允许 | 不返回受保护内容；匿名用户可重定向登录页 |
| 404 | 资源不存在，或隐藏无权访问的对象 | 不暴露对象是否真实存在 |
| 405 | 使用未允许的 HTTP 方法 | 拒绝请求并保留数据不变 |
| 409 | 唯一性冲突、并发修改冲突或非法状态转换 | 事务回滚，并提示用户刷新或修正输入 |
| 429 | 登录或密码重置请求超过限频 | 提示稍后重试，不执行受限操作 |
| 500 | 未预期的服务器错误 | 记录不含敏感数据的错误日志，显示通用错误页 |
