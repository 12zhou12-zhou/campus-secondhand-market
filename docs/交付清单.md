## 二、禁止提交

- 本地虚拟环境（`venv/`、`.venv/`）
- 运行数据库（`db.sqlite3` 等）
- 真实上传材料与商品图片（`media/`、`uploads/`）
- 真实 `.env`、密钥、口令、令牌（只保留 `.env.example`）
- 缓存文件（`__pycache__/`、`node_modules/`、日志）
- `.git` 目录（课程压缩包导出时不得包含）

## 三、版本与发布

1. 功能与测试达标后，打 Git Tag（如 `v1.0`）并创建 Release，附 Release Notes。
2. 课程平台如需压缩包，从对应 Release 导出。
3. 演示数据使用虚构信息，不得使用真实学生、卖家或管理员敏感材料。
4. 交付版本须能按 README 在干净环境完成依赖安装、迁移、系统检查、测试和启动。
