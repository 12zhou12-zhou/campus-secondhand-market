# 备份恢复演练记录

## 1. 备份策略（来自 SRS 4.3）

- 数据库和上传附件至少每日备份一次，保留最近 7 份每日备份。
- SQLite 运行中备份必须使用一致性备份方式，不得直接复制可能处于写入中的不一致文件。
- 业务审计记录不随普通运行日志清理而删除。
